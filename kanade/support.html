Kanade MIDI Player サポート

English version below

Kanade MIDI Player は、88鍵の鍵盤表示と落下ノーツでMIDIの演奏を見ながら聴ける Mac用プレーヤーです。お手持ちのSMF・RCP・banbro形式の楽曲データを再生し、 GS/XGの音色名を画面に表示しながら、内蔵音源または外部のMIDI音源で鳴らせます。

よくある質問

  • 対応している形式は？ — SMF(.mid / .midi)、RMI(.rmi)、KAR(.kar)、RCP形式(.rcp / .r36 / .g36 / .g18)、 banbro形式(.bbs / .bdx / .bbp)に対応しています
  • 音が鳴らない — まず出力先の設定をご確認ください。内蔵音源と外部のMIDI出力ポートの どちらを選んでいるかで、確認すべき点が変わります。外部音源をお使いの 場合は、音源本体の電源が入っているか、Macと正しく接続されているかも あわせてご確認ください
  • 外部のMIDI音源が無くても使えますか？ — はい。内蔵音源(macOS標準のGS音色)だけで再生できます。外部音源は お持ちの場合に、より忠実な音を鳴らすための選択肢です
  • 持ち込みのSoundFontは必須ですか？ — いいえ、不要です。内蔵音源はmacOS標準のGS音色を使うため、追加の SoundFontが無くても鳴ります。お手持ちのSoundFont/DLSファイルに 差し替えて使うこともできます

Kanade MIDI Player Support (English)

Kanade MIDI Player is a Mac app for playing MIDI song files, with an 88-key keyboard display and falling notes so you can see the performance while you listen. It plays your own SMF, RCP, and banbro format song data, shows GS/XG tone names on screen, and can output to the built-in synth or external MIDI hardware.

Frequently asked questions

  • Which formats are supported? — SMF (.mid / .midi), RMI (.rmi), KAR (.kar), RCP format (.rcp / .r36 / .g36 / .g18), and banbro format (.bbs / .bdx / .bbp).
  • No sound? — Check your output setting first. What to check depends on whether you've selected the built-in synth or an external MIDI port. If you're using an external synth, also make sure it's powered on and correctly connected to your Mac.
  • Can I use it without external MIDI hardware? — Yes. The app plays fully using only the built-in synth (macOS's GS tone set). External hardware is an option if you have it, for more faithful sound.
  • Do I need to bring my own SoundFont? — No. The built-in synth uses macOS's GS tone set, so it plays without any additional SoundFont. If you have your own SoundFont/DLS file, you can use it instead.
