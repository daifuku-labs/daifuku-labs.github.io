Kanade MIDI Player サポート

English version below

Kanade MIDI Player は、88 鍵の鍵盤表示と落ちてくるノーツで MIDI の演奏を見ながら聴ける Mac 用プレーヤーです。お手持ちの SMF・RCP・banbro・SMAF 形式のファイルを、GS / XG の音色名を画面に表示しつつ、内蔵音源または外部の MIDI 音源で鳴らせます。

よくある質問

  • 対応している形式は？ — SMF（.mid / .midi）、RMI（.rmi）、KAR（.kar）、RCP 形式（.rcp / .r36 / .g36 / .g18）、 banbro 形式（.bbs / .bdx / .bbp）、SMAF（.mmf）です。歌詞と演出を表示する WRD（.wrd / .sry）も読み込みます
  • 音が鳴らない — まず出力先の設定をご確認ください。内蔵音源と外部の MIDI 出力ポートの どちらを選んでいるかで、確認すべき点が変わります。外部音源をお使いの 場合は、音源本体の電源が入っているか、Mac と正しく接続されているかも あわせてご確認ください
  • 外部の MIDI 音源がなくても使えますか？ — はい。内蔵音源（macOS 標準の GS 音色）だけで再生できます。外部音源は、お持ちであれば、より忠実な音で鳴らすための選択肢です
  • SoundFont は自分で用意する必要がありますか？ — いいえ。内蔵音源は macOS 標準の GS 音色を使うため、SoundFont を追加しなくても鳴ります。お手持ちの SoundFont / DLS ファイルに差し替えて使うこともできます

商標について

GS はローランド株式会社の、XG はヤマハ株式会社の登録商標です。SMAF はヤマハ株式会社が開発した着信メロディの形式です。その他の製品名は各社の商標または登録商標です。本アプリは、ローランド株式会社・ヤマハ株式会社のいずれとも無関係です。

Kanade MIDI Player Support (English)

Kanade MIDI Player is a Mac app for playing MIDI song files, with an 88-key keyboard display and falling notes so you can see the performance while you listen. It plays your SMF, RCP, banbro, and SMAF files through the built-in synth or external MIDI hardware, showing GS and XG tone names on screen.

Frequently asked questions

  • Which formats are supported? — SMF (.mid / .midi), RMI (.rmi), KAR (.kar), RCP (.rcp / .r36 / .g36 / .g18), banbro (.bbs / .bdx / .bbp), and SMAF (.mmf). WRD files (.wrd / .sry), which carry lyrics and effects, are read as well.
  • No sound? — Check the MIDI output setting first. What to check depends on whether you’ve chosen the built-in synth or an external MIDI port. If you’re using an external synth, also make sure it’s turned on and connected to your Mac.
  • Can I use it without external MIDI hardware? — Yes. It works with just the built-in synth, which uses the GS tone set that comes with macOS. External hardware is optional — a step up in fidelity if you have it.
  • Do I need my own SoundFont? — No. The built-in synth uses the GS tone set that comes with macOS, so no extra SoundFont is needed. If you have your own SoundFont or DLS file, you can use that instead.
