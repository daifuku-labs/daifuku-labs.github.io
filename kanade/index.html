ノーツを可視化

鍵盤に向かってノーツが流れます。どのパートがどこを弾いているのかが、聴く前に分かります。

ドラムだって可視化

キック、スネア、ハイハット、タムを別々のレーンで表示します。パターンがそのまま読めます。

16 パートを一度に。

88 鍵の鍵盤をパートの数だけ縦に並べた FULL 表示。全体の動きを俯瞰できます。

GS / XG だって、きちんと再生。

GSやXG向けのMIDIなどを再生しても、近い音色に置き換えて再生します。パートが歯抜けになりません。

内蔵音源、外部音源、もちろんどちらも使えます。

Mac 標準の音源や SoundFont のほか、USB・Bluetoothなどで繋いだハードウェアMIDI音源も当然使えます。

数十年間のコレクションが、今息を吹き返す。

  • SMF.mid / .midi / .rmi / .kar
  • RCP.rcp / .r36 / .g36 / .g18
  • banbro.bbs / .bdx / .bbp

あの頃の MIDI を、今の Mac で。

手元のファイルを、そのまま開いてください。
